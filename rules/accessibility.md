# Accessibility Rules
- Target WCAG 2.2 AA where applicable.
- Semantic HTML on web and accessible labels/roles on React Native.
- Keyboard navigation for web critical workflows.
- Visible focus ring, accessible contrast and non-color status cues.
- Support text scaling and screen reader for mobile.
- Touch targets minimum 44 x 44 pt on mobile.
- Respect reduced-motion settings.
