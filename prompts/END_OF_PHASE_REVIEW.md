# End-of-Phase Review Prompt

Review the implementation of the current phase against its build and test prompt. Inspect the actual code, database migrations and tests. Verify no future-phase scope was implemented in a way that creates technical debt. Run lint, typecheck, relevant tests and affected app builds. Run the standard end-of-phase validation chain: the phase test prompt, **Playwright E2E** (embedded PostgreSQL + API up, screenshots to `apps/web/e2e/screenshots/`) and **Storybook component tests** (static build + test-runner, stories for every new/changed UI primitive, screenshots to `docs/screenshots/storybook/` via `node scripts/storybook-screenshots.mjs`). Update `docs/IMPLEMENTATION_STATUS.md`, `CHANGELOG.md`, and `docs/DECISIONS.md`; refresh the README screenshots section. Commit and push to GitHub with the refreshed screenshots. State whether it is safe to proceed. If not, fix blockers and re-run tests. Do not begin a new phase.
